## Part 3. Настройка сети ОС

- Чтобы задать имя машины, необходимо воспользоваться командой `sudo hostnamectl set-hostname user-1`

<img src="images/Screenshot%202025-01-15%20at%209.56.30%20PM.png" alt="Имя машины" width="600">

- Чтобы установить временную зону, необходимо воспользоваться командой `sudo timedatectl set-timezone <timezone>`

<img src="images/Screenshot%202025-01-15%20at%209.59.05%20PM.png" alt="Временная зона" width="600">

- Чтобы вывести сетевые интерфейсы, можно воспользоваться командой `ip link show`

> Интерфейс `lo` расшифровывается как `loopback` и обозначает виртуальный сетевой интерфейс, предназначенный для обмена данными внутри устройства, без выхода в физическую сеть. Интерфейс всегда имеет IP-адрес `127.0.0.1`, который также известен как `localhost`.

<img src="images/Screenshot%202025-01-15%20at%2010.01.18%20PM.png" alt="Сетевые интерфейсы" width="600">

- Чтобы получить IP-адрес от DHCP, можно воспользоваться командой `ip addr show`

> DHCP (Dynamic Host Configuration Protocol) — это сетевой протокол, который используется для автоматической настройки параметров сетевых устройств в IP-сетях. Основная задача DHCP — предоставить клиентским устройствам (например, компьютерам, смартфонам, принтерам) необходимые параметры для подключения к сети, такие как IP-адрес, маска подсети, шлюз по умолчанию и адреса DNS-серверов.

<img src="images/Screenshot%202025-01-15%20at%2010.03.57%20PM.png" alt="Просмотр внешнего IP" width="600">

- Для настройки статического IP необходимо отредактировать файл `/etc/netplan/<network-name>.yaml` примерно так:
```yaml
network:
  version: 2
  ethernets:
    eth0:
      dhcp4: false
      addresses:
        - 192.168.1.100/24
      gateway4: 192.168.1.1
      nameservers:
        addresses:
          - 8.8.8.8
          - 8.8.4.4
```

<img src="images/Screenshot%202025-01-16%20at%202.26.13%20PM.png" alt="Настройка статического IP" width="600">

- После изменений конфигурации её необходимо применить, для этого использовать команду `sudo netplan apply`

<img src="images/Screenshot%202025-01-16%20at%201.45.15%20PM.png" alt="Применение конфигурации" width="600">

- На данном шаге необходимо перезагрузить устройство, например, через команду `sudo reboot`
- Проверка конфигурации, используя команду `ip addr show`

<img src="images/Screenshot%202025-01-16%20at%202.31.07%20PM.png" alt="Проверка конфигурации" width="600">

- Проверка подключения, используя команду `ping`

<img src="images/Screenshot%202025-01-16%20at%202.18.16%20PM.png" alt="ping" width="600">

> `sudo` (сокращение от "superuser do") — это команда в Unix-подобных операционных системах, которая позволяет пользователям выполнять команды с привилегиями суперпользователя (root) или другого пользователя.

#### vim

- Для запуска необходимо прописать команду в терминале `vim <filepath>`.
- Для начала редактирования необходимо перейти в режим вставки, используя `i` (Обозначает `insert`) или `a` (Обозначает `append`).
- Для сохранения необходимо выйти из режима редактирования, нажав клавишу `Esc` и прописать команду сохранения `:w` (Обозначает `write`).
- Для выхода из текстового редактора необходимо воспользоваться командой `:q` (Обозначает `quit`).
- Можно сочетать команды, например, для сохранения и выхода `:wq`
- Для выхода без сохранения необходимо использовать команду принудительного выхода `:!q`.

## Part 8. Установка и базовая настройка сервиса **SSHD**

> SSH (Secure Shell) — это протокол для безопасного удаленного доступа к компьютерам по сети. Служба SSHd (SSH Daemon) реализует серверную часть этого протокола.

- Для установки службы SSHd использовалась команда `sudo apt install openssh-server`.

<img src="images/Screenshot%202025-01-17%20at%207.27.45%20PM.png" alt="Установка SSHd" width="600">

- После этого служба была добавлена в автозапуск с помощью команды `sudo systemctl enable ssh`

<img src="images/Screenshot%202025-01-17%20at%207.29.11%20PM.png" alt="Добавление в автозапуск" width="600">

- Порт SSH был изменен на 2022. Для этого в файле `/etc/ssh/sshd_config` параметр `Port` был установлен равным `2022`.

<img src="images/Screenshot%202025-01-17%20at%207.54.07%20PM.png" alt="Перенастройка порта" width="600">

- После этого изменения конфигурации применены командой `sudo systemctl restart ssh`.

- Наличие процесса SSHd проверено с помощью команды `ps aux | grep sshd`. Значение команды и ключей:
  - `ps` - отображает список процессов.
  - `a` - показывает процессы всех пользователей.
  - `u` - выводит информацию в формате пользователя, CPU и памяти.
  - `x` - отображает процессы, не привязанные к терминалу.

<img src="images/Screenshot%202025-01-17%20at%208.07.43%20PM.png" alt="Проверка процесса" width="600">

- После необходимо перезагрузить систему, используя `sudo reboot`

- Для проверки активного порта использовалась команда `netstat -tan`. Порт 2022 находится в состоянии `LISTEN`. Значения ключей:  
  - `-t` - показывает TCP-соединения,  
  - `-a` - все соединения,  
  - `-n` - числовой формат адресов.  

Адрес `0.0.0.0` означает, что соединения принимаются на всех интерфейсах.

<img src="images/Screenshot%202025-01-17%20at%208.30.56%20PM.png" alt="Проверка порта" width="600">

## Part 15. Использование планировщика заданий **CRON**

> **cron** — это планировщик задач в Unix-подобных операционных системах, который позволяет автоматически выполнять команды или скрипты в заданное время или с определенной периодичностью.

- Для использования планировщика заданий необходимо вызвать команду `crontab -e`, которая предложит выбрать текстовый редактор для изменений конфигураций (по умолчанию `nano`).
- После чего будет открыт файл, в котором есть шаблоны и инструкции. В конец файла будет добавлена строка: `*/2 * * * * /usr/bin/uptime`, где
  - Расписание (`*/2 * * * *`):
    - `*/2` — это означает, что задание будет выполняться каждые 2 минуты.
    - Остальные символы (`* * *`) представляют собой поля для часов, дней месяца, месяцев и дней недели. Звездочка (`*`) означает "каждый" (т.е. любое значение).
  - Команда (`/usr/bin/uptime`).
    - Это полный путь к исполняемому файлу **uptime**, который показывает, как долго работает система, количество пользователей и среднюю загрузку.

<img src="images/Screenshot%202025-01-19%20at%209.50.19%20PM.png" alt="Задание планировщика" width="600">

- Для проверки работоспособности задач в планировщике можно просмотртеть системные логи планировщика **CRON** `grep CRON /var/log/syslog`

<img src="images/Screenshot%202025-01-19%20at%2010.10.51%20PM.png" alt="Результат работы планировщика" width="600">

- Для просмотра всех задач планировщика можно использовать команду `crontab -l`

<img src="images/Screenshot%202025-01-19%20at%2010.12.46%20PM.png" alt="Просмотр задач планировщика" width="600">

- Для удаления всех заданий планировщика можно использовать команду `crontab -r`, а после вновь просмотреть список задач в нём.

<img src="images/Screenshot%202025-01-19%20at%2010.13.27%20PM.png" alt="Удаление заданий планировщика" width="600">
